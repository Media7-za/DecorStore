From Zero to Live Store

01
Brief the Agent
Write a CLAUDE.md with your store vision, brand palette, product categories, and target customer. This is the agent's north star.
02
Run Phase 1–2
Agent scaffolds the Next.js + Medusa project and builds all storefront UI. Review and approve the visual output.
03
Connect Services
Provide API keys for Stripe, Cloudinary, Algolia. Agent wires all integrations via MCP, tests end-to-end checkout.
04
Populate Catalog
Give agent a CSV of products. It seeds the DB, generates AI descriptions, uploads images, and indexes search.
05
Deploy & Go Live
Agent deploys to Vercel + Fly.io, configures domain, sets up monitoring. Store is live and fully operational.
